## Projeto: Pintores do Mundo 🎨

Este projeto é uma aplicação web que permite aos usuários pesquisar informações sobre pintores renomados de diversas épocas e estilos. A aplicação é intuitiva, oferecendo uma breve descrição e links para mais informações sobre cada artista.

Acesse o projeto online: [Pintores do Mundo](https://pintores-mundo.vercel.app/)

---

## Funcionalidades 🖌️

- **Pesquisa Interativa:** Permite buscar pintores por nome, descrição ou tags associadas.
- **Resultados Detalhados:** Exibe o nome, uma breve descrição e um link para mais informações sobre cada pintor.
- **Interface Simples e Acessível:** Design minimalista focado na usabilidade.

---

## Tecnologias Utilizadas 💻

- **HTML5:** Estrutura básica da aplicação.
- **CSS3:** Estilização e layout responsivo.
- **JavaScript:** Lógica de pesquisa e manipulação DOM.

---

## Estrutura do Projeto 📂

- **index.html:** Estrutura principal da aplicação.
- **style.css:** Arquivo de estilos para a página.
- **app.js:** Lógica de pesquisa e exibição de resultados.
- **dados.js:** Base de dados local com informações sobre pintores.

---

## Como Utilizar 📘

1. **Acesse a Aplicação:**
   - Visite [Pintores do Mundo](https://pintores-mundo.vercel.app/).

2. **Pesquisar:**
   - Digite o nome de um pintor, um estilo ou uma característica no campo de pesquisa.
   - Clique no botão "Pesquisar" para visualizar os resultados.

3. **Explorar Resultados:**
   - Clique no título de um pintor para acessar mais informações através do link fornecido.

---
